# 🍋 Insta Limón

Aplicación ligera y rápida para Windows diseñada para grabar tu pantalla al instante desde la bandeja del sistema (*System Tray*).

Desarrollado por **GatekoNeko** (**Otún Pro**).

---

## ✨ Características
* **Acceso inmediato:** Se integra discretamente en la bandeja del sistema de Windows sin estorbar en tu barra de tareas.
* **Encuadres listos para redes:** Selector rápido de relación de aspecto (**16:9**, **9:16** y **1:1**) con previsualización directa.
* **Control total de audio:** Ajuste independiente de volumen para tu micrófono y el audio interno del sistema.

---

## 📥 Descarga e Instalación

Ve a la sección de **[Releases (Lanzamientos)](../../releases)** a la derecha de esta página y elige la opción que prefieras:

* **Instalador recomendado (`InstaLimon_v1.3.2_Setup.exe`):** Ejecuta el asistente tradicional de Windows para instalar el programa y crear sus accesos directos.
* **Versión Portable (`InstaLimon_v1.3.2_Portable.zip`):** Descomprime la carpeta en cualquier lugar y ejecuta `Insta Limón.exe` directamente sin necesidad de instalar nada.

### Requisitos del sistema
* Windows 10 o Windows 11 (64 bits).
